# Indovina Chi?

Un gioco browser-based ispirato al classico *Indovina Chi?*, giocabile online da 2 a 3 giocatori contemporaneamente senza bisogno di registrazione.

## Caratteristiche
- **Multiplayer in tempo reale:** Connessione diretta P2P tra giocatori tramite PeerJS.
- **Categorie personalizzabili:** Supporto per più categorie di carte (YouTuber, Videogiochi, Pokémon, ecc.).
- **Nessun server backend richiesto:** Funziona interamente lato client ed è ospitato su GitHub Pages.
- **Interfaccia responsive:** Ottimizzato per PC, tablet e smartphone.

## Come giocare
1. Apri la pagina del sito.
2. Inserisci il tuo nome utente.
3. **Crea una stanza:** Scegli la categoria di gioco e condividi il codice a 5 lettere generato con i tuoi amici.
4. **Entra in una stanza:** Inserisci il codice fornito dall'host e clicca su *Entra*.
5. Scegli la tua carta segreta, fermala con il tasto *Conferma* e usa la chat per fare le domande ed eliminare i sospetti dal tabellone!

## Tecnologie utilizzate
- HTML5, CSS3, JavaScript (Vanilla ES6)
- [PeerJS](https://peerjs.com/) (WebRTC per la gestione delle connessioni P2P)
- Google Fonts (*Fredoka*)
